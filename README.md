A phoenix of golden embers soaring through a deep indigo night sky, wings spread against the dark and trailing sparks, for make.fun's "Make the coolest art" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.jpg` to `$MAKEFUN_OUTPUT_DIR/entry.png`. It is a pure copy, so every run writes exactly the same bytes: no network, no randomness, no timestamps.

The output is a whole JPEG, 1024 by 1024 pixels, 362,426 bytes — under the 1 MiB limit.

The phoenix was chosen for the entry over a neon koi over a rainy Neo Tokyo street: fire and night sky read at a glance, which is what a pairwise judge rewards.
